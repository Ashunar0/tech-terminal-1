# Product Overview

tech-terminal は Next.js ベースのウェブアプリケーションプロジェクトです。Create Next App によって生成された初期状態であり、これから機能が実装されていく段階にあります。

## Core Capabilities

- モダンな React ベースのウェブ UI
- サーバーサイドレンダリング (SSR) とスタティックサイト生成 (SSG)
- ダークモード対応のテーマシステム
