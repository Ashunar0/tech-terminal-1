# Implementation Plan

## Tasks

- [ ] 1. プロジェクト基盤セットアップ
- [x] 1.1 Firebase 環境構築
  - Firebase SDK をインストールし、プロジェクトに接続する
  - 環境変数で Firebase 設定を管理する
  - Firestore コレクション `articles` を作成し、開発用のセキュリティルールを設定する
  - _Requirements: 7.1_

- [x] 1.2 shadcn/ui コンポーネントの追加
  - 必要なコンポーネントをインストール（card, input, textarea, select, button, badge, dialog, alert-dialog, skeleton）
  - コンポーネントが正しく動作することを確認
  - _Requirements: 8.1, 8.2, 8.3, 8.4_

- [x] 1.3 (P) OGP パースライブラリのセットアップ
  - open-graph-scraper をインストール
  - 型定義を確認し、必要に応じて追加
  - _Requirements: 2.1, 2.6_

- [ ] 2. データ層の実装
- [x] 2.1 記事データの型定義
  - Article 型と ArticleInput 型を定義する
  - Course 型（python, web, gameapp, other）を定義する
  - Firestore Timestamp と Date の変換ユーティリティを作成する
  - _Requirements: 7.2_

- [x] 2.2 記事サービスの実装
  - Firestore への記事の追加機能を実装する
  - 記事一覧の取得機能を実装する（作成日時の降順）
  - 記事の更新機能を実装する（updatedAt を自動更新）
  - 記事の削除機能を実装する
  - _Requirements: 1.4, 6.4, 6.6, 7.1, 7.2, 7.3, 7.4_

- [ ] 3. API 層の実装
- [x] 3.1 OGP 取得 API エンドポイントの作成
  - Route Handler で URL パラメータを受け取る
  - open-graph-scraper を使用して OGP 情報を取得する
  - タイトル、サムネイル URL、説明を返却する
  - タイムアウト（5秒）を設定し、エラー時は空データを返す
  - URL バリデーションを実装する
  - _Requirements: 2.1, 2.2, 2.4, 2.5, 2.6_

- [ ] 4. UI コンポーネントの実装
- [x] 4.1 (P) 記事カードコンポーネントの作成
  - サムネイル画像、タイトル、コース、タグ、投稿者名、登録日時を表示する
  - カードクリックで元記事を新しいタブで開く
  - 編集・削除ボタンを配置する
  - 画像読み込みエラー時のプレースホルダーを実装する
  - _Requirements: 3.2, 3.4, 3.6, 6.1_

- [x] 4.2 (P) 検索バーコンポーネントの作成
  - キーワード入力フィールドを実装する
  - 入力時のデバウンス処理（300ms）を実装する
  - クリアボタンを実装する
  - _Requirements: 5.1, 5.5_

- [x] 4.3 (P) フィルターバーコンポーネントの作成
  - コース選択ドロップダウンを実装する（全て / Python / Web / GameApp / Other）
  - タグ選択 UI を実装する（Badge をクリックで選択/解除）
  - _Requirements: 4.1, 4.3_

- [x] 4.4 記事フォームコンポーネントの作成
  - URL 入力フィールドとバリデーションを実装する
  - URL 入力時に OGP API を呼び出し、タイトルとサムネイルを自動取得する
  - OGP 取得中のローディング表示を実装する
  - タイトル、コース選択、タグ入力、メモ、投稿者名のフィールドを実装する
  - 必須項目のバリデーションとエラー表示を実装する
  - 新規登録モードと編集モードを切り替え可能にする
  - _Requirements: 1.1, 1.2, 1.3, 1.6, 1.7, 1.8, 2.3, 2.5, 6.2, 6.3_

- [x] 4.5 削除確認ダイアログの作成
  - AlertDialog で削除確認を表示する
  - 削除対象の記事タイトルを表示する
  - キャンセルと削除ボタンを実装する
  - _Requirements: 6.5, 6.7_

- [x] 4.6 (P) 空状態・ローディングコンポーネントの作成
  - 記事が 0 件の場合のメッセージと記事追加への誘導を表示する
  - フィルター/検索結果が 0 件の場合のメッセージを表示する
  - データ読み込み中のスケルトン表示を実装する
  - _Requirements: 3.5, 4.6, 5.4_

- [ ] 5. ページ統合
- [ ] 5.1 記事一覧ページの構築
  - トップページに記事一覧を表示する
  - 検索バーとフィルターバーを配置する
  - 記事追加ボタンを配置する
  - レスポンシブグリッドレイアウトを実装する（PC: グリッド、モバイル: シングルカラム）
  - _Requirements: 3.1, 3.3, 8.1, 8.2, 8.3_

- [ ] 5.2 フィルタリング・検索ロジックの統合
  - コースフィルターの適用ロジックを実装する
  - タグフィルターの適用ロジックを実装する
  - キーワード検索（タイトル・タグの部分一致）を実装する
  - フィルターと検索の AND 条件適用を実装する
  - _Requirements: 4.2, 4.4, 4.5, 5.2, 5.3_

- [ ] 5.3 記事登録フローの統合
  - 記事追加ボタンクリックでフォームダイアログを開く
  - フォーム送信後、記事一覧を更新して新規記事を表示する
  - _Requirements: 1.1, 1.4, 1.5_

- [ ] 5.4 記事編集・削除フローの統合
  - 編集ボタンクリックで既存データを読み込んだフォームを開く
  - 保存後、記事一覧を更新する
  - 削除ボタンクリックで確認ダイアログを表示する
  - 削除確認後、記事一覧から該当記事を除去する
  - _Requirements: 6.2, 6.4, 6.5, 6.6_

- [ ] 6. 仕上げ
- [ ] 6.1 ダークモード対応
  - CSS 変数によるテーマ切り替えを確認する
  - 全コンポーネントのダークモード表示を検証する
  - _Requirements: 8.4_

- [ ] 6.2 エラーハンドリングの強化
  - Firestore 接続エラー時のメッセージ表示を実装する
  - 各種エラー状態の UI を確認する
  - _Requirements: 7.4_

- [ ] 6.3 動作確認とバグ修正
  - 記事の追加・編集・削除の一連の操作を検証する
  - フィルタリング・検索の動作を検証する
  - レスポンシブレイアウトを検証する
  - OGP 取得の正常系・エラー系を検証する
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 2.1, 2.2, 2.3, 2.4, 3.1, 3.2, 3.3, 3.4, 4.1, 4.2, 4.3, 4.4, 5.1, 5.2, 6.1, 6.2, 6.3, 6.4, 6.5, 6.6, 8.1, 8.2, 8.3_
